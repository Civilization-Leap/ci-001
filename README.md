**Before the last effective path disappears.**

CI-001 is an independent audit tool for checking whether an affected party can still correct, exit or recover meaningful choice in a particular system. Start with one party, one capacity and one time window.

| C | E | R |
| --- | --- | --- |
| Executable correction | Meaningful exit or refusal | Current recovery conditions |

Record **1** (verified effective), **0** (verified failed) or **?** (insufficient evidence). **R = 0 does not mean permanent loss.** After recording C/E/R, assess rebuilding separately under §2.4. Only 0/0/0 plus sufficient irreversibility evidence supports a scoped irreversible-closure finding.

**Start here:** [English one-page Word form](forms/CI-001_V1.4_One-page_Audit_Form_EN.docx) · [中文一页 Word 表](forms/CI-001_V1.4_一页可填审计表_中文.docx) · [all form formats](forms/README.md). Allow about an hour for a first pass; attach evidence by ID and leave unsupported items unknown. Developers, laboratories, operators, auditors and affected parties can use it. Self-assessment supplies no third-party enforcement or certification authority.

**Need the rules?** [English manual](docs/en/criterion.md) · [Chinese original](docs/zh/criterion.md). Chinese governs interpretive differences; substantive corrections must update both languages in one change. Source theory appears in §8; no prior acceptance of it is needed.
