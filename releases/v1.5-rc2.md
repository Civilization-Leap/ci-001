## Targeted changes / 定向修订

Institutional gaps now have explicit recording and authority limits; critical windows use closing events, evidence, uncertainty and end-to-end execution time; unanswered evidence requests have review triggers without converting unknown to failure. The compact guide provides non-exhaustive C/E/R checks. Existing hypothetical evidence records illustrate timing and nonresponse.

补齐机构缺位时的记录及权限边界、关键窗口估算、持证方未响应的复核触发条件。保留“未知不自动转0”、候选主体预保护与处置自约束。精简指引提供C/E/R核验要点，原有完整假设样例补充窗口和未响应处理。

## Artifact identity / 文件身份

The 42-file review package is preserved byte-for-byte from its checked pre-publication snapshot. Its “unpublished” wording and verification-time GitHub status describe that snapshot; this release makes those review artifacts publicly available, without declaring a formal edition. The blank and completed one-page forms retain unchanged F1.1-RC1 bytes and historical filenames. Use V1.5-RC2 in A1 for new assessments. The manual and guide are V1.5-RC2.
