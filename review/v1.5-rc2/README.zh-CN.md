# CI-001 · 不可逆封闭判据

**V1.5-RC2 · 审阅候选，未发布 · F1.1-RC1**

在最后一条有效路径消失之前。

本工具检查具体主体的一项关键能力是否仍具备纠错C、退出或拒绝E、当前恢复R。1＝已核验有效；0＝已核验失效；?＝证据不足。R＝0不等于不可逆；0/0/0还须按§2.4另判。

**先看填法：** [一页已填示例](examples/HYP-001_Filled_ZH.docx) → [完整假设证据](examples/HYP-001_ZH.md) → [填写指南](forms/Guide_ZH.md)。

正文与指南为V1.5-RC2；空白表和一页已填表原样保留F1.1-RC1及其历史标识，与本轮16字段兼容。新评估在A1注明V1.5-RC2；已填表为教学假设。

**开始填写：** [中文一页Word表](forms/CI-001_V1.5-RC1_一页可填审计表_中文.docx) · [English Word form](forms/CI-001_V1.5-RC1_One-page_Audit_Form_EN.docx) · [全部格式与填写指引](forms/README.md)。选一个主体、一项关键能力、一个范围与时间窗口。开发方、实验室、运营团队、审查者和受影响者本人均可使用；在A1注明身份、利益关系和实际权限。

**怎样开始：** 先整理已有证据，允许部分填写并保留未知。约一小时只是初步整理的规划估计；完整取证、测试与独立复核另计。任务内拒绝和关系整体退出如果属于不同评估单元，应分别填写。证据在系统外部时，记录持有方、请求状态与复核时点，不把自己没有权限取得的证据写成已经不存在。

**结果的效力：** 自评估可以报告证据与初步判断，不赋予对第三方执法或独立裁决权限，也不构成独立认证。
